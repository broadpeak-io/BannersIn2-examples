# pause-ads

When the viewer pauses playback, the player requests a pause ad and shows it as a SIMID overlay on the paused frame. Resuming playback (or the creative's own resume action) dismisses it.

| Platform | Status |
| --- | --- |
| [Web](web) | available (Shaka Player) |
| Android | planned |
| iOS | planned |

## Prerequisite: a service

You need a Broadpeak.io service configured for pause ads. Follow the playbook on [developers.broadpeak.io](https://developers.broadpeak.io/docs/introduction) (Pause Ads), which ends with a service URL. No URL is included in this repository.
